# Как передать скилл ChatGPT / Claude / Codex

Распакуйте ZIP. В среде с поддержкой skills импортируйте папку `amnezia-two-hop` (в Codex обычно `~/.codex/skills/amnezia-two-hop`, в Claude используйте доступный в вашей версии импорт пользовательского skill). Если импорта нет, прикрепите ZIP или все файлы папки и отправьте текст ниже.

> Используй приложенный скилл amnezia-two-hop. Хочу настроить российский входной VPS с AmneziaWG и выборочный выход выбранных сервисов через зарубежный VPS. Сначала проверь доступность терминала и SSH. Создай локальную папку VPN-Automation с шаблоном servers.private.json вне облачной синхронизации, если я ещё не указал путь. Я заполню доступы локально. Затем выполняй настройку, проверки и резервное копирование самостоятельно по SKILL.md. Не выводи пароли и ключи в чат. Не изменяй работающие серверы до обследования и резервной копии. Не покупай и не удаляй серверы.

На существующей схеме укажите `mode: repair`, для новых серверов — `install`. При следующем запуске достаточно написать путь к `servers.private.json`. Создание шаблона не подключается к серверу.

**Ограничение:** загрузка скилла не даёт чату доступ к компьютеру, SSH или GUI. Нужен агент с такими инструментами и разрешённой сетью. Если инструментов нет, автономная настройка невозможна. Подтверждение ключа незнакомого SSH-сервера, разрешения ОС/инструментов, импорт VPN на телефоне и тесты без доступа к устройству могут потребовать участия владельца. Скилл не обещает обход этих ограничений.

Доступы не прикрепляйте к обычному чату. Шаблон формата: [references/input.md](references/input.md). В ZIP нет настоящих паролей, SSH/WireGuard ключей или VPN-профилей. Обновлённые backup/QR и файл доступов никогда не добавляйте в переносимый ZIP.

Комплект включает инструкции для агента и SSH-helper, а не готовый универсальный установщик любой версии Amnezia. Реальное развёртывание новых серверов ещё требует исполнения и проверок агентом; этот комплект сам по себе на VPS ничего не меняет.

Проверено при подготовке 21.11.2026: формат SKILL.md; четыре локальных теста — сохранение существующего файла доступов, отклонение неверного host key до авторизации, выполнение скрипта по SSH с сохранением exit code и маскировкой тестового пароля, получение неподтверждённого fingerprint без авторизации. Полное развёртывание на чистых VPS, импорт в разные версии ChatGPT/Claude и восстановление из backup этим комплектом ещё не тестировались. При необходимости агент запускает `python scripts/test_control.py -v` в среде с Paramiko.
